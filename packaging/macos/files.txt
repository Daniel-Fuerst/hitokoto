# S049 (decision 5): the files of hitokoto.app, relative to the bundle. A framework counts as one
# entry (its folder); everything else is a file or a symbolic link of its own. A file more or less
# makes the build and the check red. macdeployqt decides the Qt part; when it changes on purpose,
# this list follows. The job summary of every build prints the bundle's list. Confirmed by the
# second dry run on pull request 80 (Qt 6.12.0, macos-15, 0.10.1): macdeployqt brings QtDBus (a Qt
# framework links it) and writes no qt.conf (Qt finds its plugins in Contents/PlugIns without one;
# install-check.sh checks that libqcocoa is loaded from there); CMake's Makefile generator writes
# no PkgInfo, which macOS does not need.
